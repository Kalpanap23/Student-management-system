# 🎓 Student Management System

## 📌 Project Description
The Student Management System is a simple web-based application that helps manage student records efficiently. It allows users to add, update, delete, and view student details easily using a user-friendly interface.

---

## 🚀 Features
- ➕ Add new student details
- ✏️ Update existing student information
- ❌ Delete student records
- 📋 Display all students in a list/table
- 💾 Data stored using browser Local Storage

---

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Local Storage (Browser)
